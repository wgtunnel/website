        <div className="platform-section">
            <h2>Stable Release</h2>

            > ⚠️ **Requirements**
            >
            > Only **systemd-based Linux distributions** are supported.
            > The firewall must use **nftables** or **iptables with the nft backend (`iptables-nft`)**.

            <h3>Debian / Ubuntu</h3>

            <p>Preferred: via the <a href="https://apt.wgtunnel.com">apt repository</a> (future updates land as regular <code>apt upgrade</code> updates):</p>

            ```bash
            curl -fsSL https://apt.wgtunnel.com/wgtunnel-archive-keyring.asc | \
              sudo gpg --dearmor -o /usr/share/keyrings/wgtunnel-archive-keyring.gpg
            echo "deb [signed-by=/usr/share/keyrings/wgtunnel-archive-keyring.gpg] https://apt.wgtunnel.com stable main" | \
              sudo tee /etc/apt/sources.list.d/wgtunnel.list
            sudo apt update
            sudo apt install wgtunnel
            ```

            <p>Or, download the <code>.deb</code> directly from the latest release:</p>

            <div className="download-container">
                <OutlinedIconButton
                    onClick={() => downloadLatestAsset('https://api.github.com/repos/wgtunnel/desktop/releases/latest', /^wgtunnel-.*-linux-amd64\.deb$/i)}
                    label="Download .deb"
                    icon={FaLinux}
                />
            </div>

            ```bash
            sudo apt install ./wgtunnel*.deb
            ```

            <h3>Fedora / RHEL</h3>

            <p>Preferred: via <a href="https://copr.fedorainfracloud.org/coprs/zaneschepke/wgtunnel/">COPR</a> (future updates land as regular <code>dnf upgrade</code> updates):</p>

            ```bash
            sudo dnf copr enable zaneschepke/wgtunnel
            sudo dnf install wgtunnel
            ```

            <p>Or, download the <code>.rpm</code> directly from the latest release:</p>

            <div className="download-container">
                <OutlinedIconButton
                    onClick={() => downloadLatestAsset('https://api.github.com/repos/wgtunnel/desktop/releases/latest', /^wgtunnel-.*-linux-x86_64\.rpm$/i)}
                    label="Download .rpm"
                    icon={FaLinux}
                />
            </div>

            ```bash
            sudo rpm -Uvh wgtunnel*.rpm
            ```

            <h3>Arch Linux</h3>

            <p>Preferred: via the <a href="https://aur.archlinux.org/packages/wgtunnel-bin">AUR</a>:</p>

            ```bash
            yay -S wgtunnel-bin
            ```

            > Per Arch packaging guidelines, this does not enable or start the daemon for you.

            ```bash
            sudo systemctl enable --now wgtunnel-daemon.service
            ```

            <p>Or, download the <code>.pacman</code> package directly from the latest release:</p>

            <div className="download-container">
                <OutlinedIconButton
                    onClick={() => downloadLatestAsset('https://api.github.com/repos/wgtunnel/desktop/releases/latest', /^wgtunnel-.*-linux-x64\.pacman$/i)}
                    label="Download .pacman"
                    icon={FaLinux}
                />
            </div>

            ```bash
            sudo pacman -U wgtunnel*.pacman
            ```

            <h3>Other distros (tarball)</h3>

            <p>Use this only if none of the formats above fit your distro.</p>

            <div className="download-container">
                <OutlinedIconButton
                    onClick={() => downloadLatestAsset('https://api.github.com/repos/wgtunnel/desktop/releases/latest', /^wgtunnel-.*-linux-x64\.tar\.gz$/i)}
                    label="Download Tarball"
                    icon={FaLinux}
                />
            </div>

            ```bash
            tar -xzf wgtunnel*-linux-x64.tar.gz
            cd wgtunnel*-linux-x64/
            sudo ./install.sh
            ```

            <small>In-app updates aren't available for direct downloads or the tarball install. See the <a href="https://github.com/wgtunnel/desktop#readme" target="_blank" rel="noopener noreferrer">desktop repository README</a> for full details on every install method.</small>
