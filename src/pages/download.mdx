    <PlatformTab value="linux" label="Linux" icon={FaLinux}>

        ## Stable Release <ReleaseVersion repo="desktop" />

        > ⚠️ **Requirements**
        >
        > The firewall must use **nftables** or **iptables with the nft backend (`iptables-nft`)**.
        > On **systemd-based distributions** the daemon starts automatically at boot. On other init
        > systems it installs but needs to be started manually (or integrated with your init system).

        ### Debian / Ubuntu

        <InstallMethods>
            <InstallMethod title="Package Manager">
                Via [our apt repository](https://apt.wgtunnel.com). Review the script [here](https://raw.githubusercontent.com/wgtunnel/desktop/master/packaging/apt/install.sh) before running it:

                ```bash
                wget -qO- https://apt.wgtunnel.com/install.sh | sh
                ```
            </InstallMethod>

            <InstallMethod title="Direct">
                Or, download the `.deb` directly from the latest release:

                <div className="download-container">
                    <OutlinedIconButton
                        onClick={() => downloadLatestAsset('https://api.github.com/repos/wgtunnel/desktop/releases/latest', /^wgtunnel-.*-linux-amd64\.deb$/i)}
                        label="Download .deb"
                        icon={FaLinux}
                    />
                </div>

                ```bash
                sudo apt install ./wgtunnel*.deb
                ```
            </InstallMethod>
        </InstallMethods>

        ### Fedora / RHEL

        <InstallMethods>
            <InstallMethod title="Package Manager">
                Via [COPR](https://copr.fedorainfracloud.org/coprs/zaneschepke/wgtunnel/) (future updates land as regular `dnf upgrade` updates):

                ```bash
                sudo dnf copr enable zaneschepke/wgtunnel
                sudo dnf install wgtunnel
                ```
            </InstallMethod>

            <InstallMethod title="Direct">
                Or, download the `.rpm` directly from the latest release:

                <div className="download-container">
                    <OutlinedIconButton
                        onClick={() => downloadLatestAsset('https://api.github.com/repos/wgtunnel/desktop/releases/latest', /^wgtunnel-.*-linux-x86_64\.rpm$/i)}
                        label="Download .rpm"
                        icon={FaLinux}
                    />
                </div>

                ```bash
                sudo rpm -Uvh wgtunnel*.rpm
                ```
            </InstallMethod>
        </InstallMethods>

        ### Arch Linux

        <InstallMethods>
            <InstallMethod title="Package Manager">
                Via the [AUR](https://aur.archlinux.org/packages/wgtunnel-bin):

                ```bash
                yay -S wgtunnel-bin
                ```
            </InstallMethod>

            <InstallMethod title="Direct">
                Or, download the `.pacman` package directly from the latest release:

                <div className="download-container">
                    <OutlinedIconButton
                        onClick={() => downloadLatestAsset('https://api.github.com/repos/wgtunnel/desktop/releases/latest', /^wgtunnel-.*-linux-x64\.pacman$/i)}
                        label="Download .pacman"
                        icon={FaLinux}
                    />
                </div>

                ```bash
                sudo pacman -U wgtunnel*.pacman
                ```
            </InstallMethod>
        </InstallMethods>

        > Per Arch packaging guidelines, this does not enable or start the daemon for you.

        ```bash
        sudo systemctl enable --now wgtunnel-daemon.service
        ```

        ### Other distros (tarball)

        Use this only if none of the formats above fit your distro.

        <div className="download-container">
            <OutlinedIconButton
                onClick={() => downloadLatestAsset('https://api.github.com/repos/wgtunnel/desktop/releases/latest', /^wgtunnel-.*-linux-x64\.tar\.gz$/i)}
                label="Download Tarball"
                icon={FaLinux}
            />
        </div>

        ```bash
        tar -xzf wgtunnel*-linux-x64.tar.gz
        cd wgtunnel*-linux-x64/
        sudo ./install.sh
        ```

        <small>In-app updates aren't available for direct downloads or the tarball install. See the <a href="https://github.com/wgtunnel/desktop#readme" target="_blank" rel="noopener noreferrer">desktop repository README</a> for full details on every install method.</small>
